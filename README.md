# Wapangaji Morogoro

## Overview
Rental property management system built for a family compound in Morogoro, Tanzania. This project also serves as my IHK Abschlussprüfung (final exam) project for the Fachinformatiker für Systemintegration (FISI) Umschulung.

## Problem Statement
Currently, the property is managed remotely using a notebook while communication with the on-site caretaker happens via WhatsApp — often with delays. There is no formal process for tenant move-in/move-out, and deposit refunds have sometimes been given without verifying damage claims first.

## Goals
- Digitize tenant records (ID, contact info, household members, rent, deposit)
- Track move-in/move-out with proper inspection and documentation
- Verify damage claims before deposit refunds
- Role-based access for owner and caretaker
- WhatsApp integration (planned)

## Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLAlchemy
- **Frontend:** HTML/CSS (Flask templates)
